# Данные

`sources.json` фиксирует адрес, редакцию, число страниц и SHA-256 каждого PDF. Полные тексты не распространяются.

`questions.jsonl`: 60 вопросов, по 20 на документ, и парные переформулировки. Доказательство хранится как интервал символов канонического текста и его хеш. `group` объединяет вопросы одной страницы; группа целиком попадает в dev или тест. Разделение один раз зафиксировано с сеед=42.

`generation.json` описывает происхождение. Вопросы создал ассистент по материалам корпуса; это не выдается за запуск внешнего API или проверку человеком. Ответы проверяются по координатам в PDF.
